# sonia-atividade
1. Porquê serve para proteger dados importantes, e se for para o GitHub qualquer pessoa vai poder invadir o sistema. 
2. O pip freeze garante que toda equipe use as bibliotecas das mesmas versões. Evitando que tenha problemas por serem utilizados diferentes computadores.
3. Vai permitir que outras pessoas manipulem os dados do Django e entre outras coisas sendo um falha grave de segurança. 
4. Funciona garantindo a segurança e limpeza. Impedindo que os arquivos desnecessários e o .env sejam partilhados no repositório.
